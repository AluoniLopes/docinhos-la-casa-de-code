# &lt;La Casa de Code /&gt; 🧁💻

E-commerce simples e temático desenvolvido para a confeitaria fictícia **La Casa de Code** — especializada em doces artesanais inspirados no universo da Tecnologia da Informação, com o slogan *"Doces com syntax error de tão bons"*.

Projeto acadêmico da disciplina de **Projeto em Empreendedorismo** do curso de **Tecnologia em Análise e Desenvolvimento de Sistemas (3º semestre)** na UNINOVE.

---

## 🎯 Objetivo do Projeto

Facilitar a rotina de vendas de uma pequena confeitaria temática e melhorar a experiência de compra do cliente de casa. O sistema permite:

* Navegar pela vitrine inicial com destaques e pelo cardápio temático (ex.: *Enroladinho de Python*, *Brownie Full-Stack*, *Cookie Cache Limpo* e *Bolo de Pote Deploy*).
* Adicionar ou remover itens no carrinho e simular o cálculo de frete.
* Preencher dados de entrega, escolher a forma de pagamento e finalizar o pedido.
